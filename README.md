# 🌲 The Mysterious Forest

**A funny, interactive fantasy adventure game built with Streamlit and GitHub Copilot.**

> Built for Major League Hacking (MLH) **Global Hack Week — “Use GitHub Copilot to Build a Simple Application”** challenge.

## 🎮 About the Project

The Mysterious Forest is a small, choice-based adventure game where players explore a mysterious forest, encounter unusual characters, collect rewards, and try to find their way home.

The forest has a personality of its own, the fox has opinions, and not every decision goes according to plan! Make choices, discover unexpected events, and see how your adventure ends.

This project explores how GitHub Copilot can help turn a simple Python game into a more interactive and visually engaging web application.

## ✨ Features

- 🌲 **Interactive adventure:** Make choices that influence the story.
- 🦊 **Funny characters:** Meet a sarcastic fox and other unusual forest residents.
- 🍄 **Random encounters:** Discover unexpected events while exploring.
- 🔑 **Inventory and rewards:** Collect items and earn stars.
- ⚡ **Energy system:** Track your progress through the adventure.
- 🏆 **Achievements:** Unlock a humorous title based on your journey.
- 🎭 **Multiple endings:** Discover four possible outcomes.
- 🔄 **Replayability:** Restart the game and explore different paths.
- 🎨 **Forest-themed interface:** Enjoy a dark green design with gold accents and illustrations.

## 🛠️ Built With

- **Python** — game logic and interactions
- **Streamlit** — interactive web interface
- **GitHub Copilot** — AI-assisted coding and iterative improvements
- **Git and GitHub** — version control and project hosting

## 🚀 Run Locally

### Prerequisites

- Python 3.10 or later
- Git

### 1. Clone the repository

```bash
git clone https://github.com/pratyushmishra9920-ship-it/ghw-mysterious-forest.git
cd ghw-mysterious-forest
```

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Launch the game

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## 🕹️ How to Play

1. Start a new adventure in the mysterious forest.
2. Read the story and choose an available action.
3. Explore the forest and interact with its characters.
4. Collect items, manage your energy, and earn stars.
5. Reach one of the four endings.
6. Play again and try different choices!
